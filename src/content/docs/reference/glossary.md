이 사이트 본문에서 링크로 연결된 용어를 모아둔 페이지다. 가나다순으로 정렬되어 있다.

## 에이전트

대화만 하는 것이 아니라, 스스로 판단해서 파일을 만들거나 고치고 명령어를 실행하는 등 실제 작업까지 수행하는 프로그램. Codex는 코딩 작업을 대신 수행하는 에이전트다.

## 터미널

글자로 된 명령어를 입력해서 컴퓨터를 조작하는 프로그램. 검은 화면에 글자만 있는 모습으로 자주 등장한다. Windows에서는 "명령 프롬프트"나 "PowerShell", macOS에서는 "터미널(Terminal)"이라는 이름으로 불린다.

## 프롬프트

Codex 같은 AI에게 보내는 요청 문장. "이런 걸 만들어줘"처럼 자연어로 작성한다.
