이 사이트 본문에서 링크로 연결된 용어를 모아둔 페이지다. 가나다순으로 정렬되어 있다.

## 에이전트

대화만 하는 것이 아니라, 스스로 판단해서 파일을 만들거나 고치고 명령어를 실행하는 등 실제 작업까지 수행하는 프로그램. Codex는 코딩 작업을 대신 수행하는 에이전트다.

## 저장소

파일과 그 변경 이력을 함께 보관하는 공간. GitHub에서 새 프로젝트를 만들면 저장소(repository) 하나가 생긴다.

## 커밋

파일을 수정한 내용을 하나의 기록으로 확정해서 저장하는 것. GitHub 웹 화면에서 파일을 올릴 때도 마지막에 커밋 버튼을 눌러야 실제로 저장된다.

## 터미널

글자로 된 명령어를 입력해서 컴퓨터를 조작하는 프로그램. 검은 화면에 글자만 있는 모습으로 자주 등장한다. Windows에서는 "명령 프롬프트"나 "PowerShell", macOS에서는 "터미널(Terminal)"이라는 이름으로 불린다.

## 풀 리퀘스트

저장소의 내용을 수정한 뒤, "이렇게 바꾸고 싶은데 반영해줘"라고 원래 저장소에 요청하는 것. GitHub에서 다른 사람의 프로젝트에 기여할 때 주로 쓰는 방법이다.

## 프롬프트

Codex 같은 AI에게 보내는 요청 문장. "이런 걸 만들어줘"처럼 자연어로 작성한다.

## 할루시네이션

AI가 틀린 내용을 마치 사실인 것처럼 확신에 찬 말투로 답하는 현상. 존재하지 않는 함수나 URL을 실제로 있는 것처럼 제시하는 경우가 대표적이다.
