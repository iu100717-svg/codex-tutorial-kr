Codex는 자주 바뀌는 제품이다. 이 페이지는 사이트의 각 섹션이 **언제, 어떤 버전을 기준으로** 검증됐는지 기록해서, 독자가 "지금 내가 보는 화면과 다르면 이 페이지가 오래된 것일 수 있다"고 판단할 수 있게 한다.

## 기록 형식

각 항목은 아래 형식으로 남긴다.

```
### YYYY-MM-DD

- 대상 버전: (검증 시점의 Codex 버전 또는 시점)
- 변경/검증 내용: (무엇을 확인했는지, 이전 기록과 무엇이 달라졌는지)
- 영향받은 페이지: (링크)
```

### 기록 없음

아직 실제 화면을 기준으로 검증된 항목이 없다. 각 페이지 frontmatter의 `verified`, `codexVersion` 값이 채워지는 대로 이 페이지에도 함께 기록한다.
