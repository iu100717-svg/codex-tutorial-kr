이 사이트 본문에서 쓴 프롬프트를 상황별로 모았다. 그대로 복사해서 괄호 부분만 바꿔 쓰면 된다.

## 처음 만들 때

[뼈대 만들기](/build/02-scaffold/)에서 쓴 프롬프트.

```
개인 포트폴리오 한 페이지 웹사이트를 만들어줘.

조건:
- HTML, CSS, JavaScript 파일만 사용해줘. 빌드 도구나 프레임워크, npm 설치는 쓰지 마.
- 파일은 index.html, style.css, script.js 세 개로 나눠줘.
- 분위기는 "(분위기 단어)"로 해줘.

페이지에 들어갈 내용:
- 이름: (이름)
- 자기소개: (한두 문장 자기소개)
- 보여줄 것: (프로젝트/관심사 1~3개)
- 연락처: (이메일 또는 SNS 링크)

다 만들고 나서 어떤 파일을 만들었는지 알려줘.
```

## 수정을 요청할 때

[고치고 다시 시키기](/build/04-iterate/)에서 쓴 프롬프트.

```
자기소개 글자가 너무 작아서 안 보여. 제목처럼 크고 굵게 바꿔줘.
```

```
전체 배경색을 (원하는 색)으로 바꾸고, 글자색은 그 배경에서 잘 보이는 색으로 맞춰줘.
```

```
휴대폰처럼 화면이 좁을 때도 글자와 버튼이 잘리지 않게 반응형으로 고쳐줘.
```

## 에러가 났을 때

[에러가 났을 때](/build/05-debug/)에서 쓴 프롬프트.

```
방금 (한 일)을 했더니 (증상)이 생겼어.
에러 메시지: (에러 메시지 그대로 붙여넣기)
원인을 찾아서 고쳐줘.
```

## 리뷰를 요청할 때

[코드 리뷰 시키기](/practice/review/)에서 쓴 프롬프트.

```
지금까지 만든 index.html, style.css, script.js 파일을 검토해줘.

확인해줬으면 하는 것:
- 접근성(스크린 리더 등으로 봐도 문제없는지)에 문제가 없는지
- 같은 코드가 불필요하게 반복되는 부분이 있는지
- 화면 크기가 작을 때 깨지는 부분이 있는지

문제를 찾으면 왜 문제인지도 설명해줘.
```
