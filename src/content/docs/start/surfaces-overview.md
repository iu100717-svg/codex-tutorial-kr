## 목표

Codex를 쓸 수 있는 창구가 여러 개라는 것을 알고, 이 사이트가 왜 앱부터 시작하는지 이해한다.

## 창구가 여러 개인 이유

Codex는 한 가지 방법으로만 쓸 수 있는 게 아니다. 컴퓨터에 설치하는 앱, 코드 편집기 안의 확장 프로그램, 웹 브라우저, [터미널](/reference/glossary/#터미널)에서 쓰는 CLI, GitHub 안에서 부르는 방식까지 총 5가지 창구가 있다.

같은 Codex를 부르는 입구가 다를 뿐이지만, 입구마다 필요한 사전 지식과 난이도가 다르다. 이 사이트는 아래 순서로, 즉 **입문자 기준으로 쉬운 것부터** 다룬다.

## 5가지 창구

1. **Codex 앱** — 컴퓨터에 설치하는 프로그램. 이 사이트의 기본 경로.
2. **IDE 확장** — VS Code 같은 코드 편집기 안에 설치해서 쓰는 방식.
3. **웹** — 브라우저에서 로그인해서 쓰는 방식.
4. **CLI** — 터미널에서 명령어로 부르는 방식.
5. **GitHub 연동** — GitHub 저장소 안에서 Codex를 호출하는 방식.

## 왜 앱부터 시작하는가

터미널이나 코드 편집기를 다뤄본 적 없어도 Codex 앱은 설치하고 로그인만 하면 바로 쓸 수 있다. 나머지 4가지 창구는 각각 편집기 사용법, 터미널 사용법, GitHub 사용법을 어느 정도 알아야 편하게 쓸 수 있다.

그래서 이 사이트는 앱을 메인 경로로 두고, 나머지 창구는 [다른 창구로도 쓰기](/surfaces/ide/) 섹션에 따로 모아뒀다. 앱으로 웹앱 만들기를 끝까지 완주한 다음에 살펴봐도 늦지 않는다.
