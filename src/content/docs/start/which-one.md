## 목표

아래 질문에 답하면서 나에게 맞는 시작 창구를 정한다.

## 질문으로 찾기

### 1. 컴퓨터에 프로그램을 설치해본 적이 있나요?

- **아니오, 잘 모르겠다** → [Codex 앱 설치](/start/install-app/)로 간다. 이 사이트의 기본 경로다.
- **네, 있다** → 다음 질문으로.

### 2. 터미널(까만 화면에 글자로 명령어를 입력하는 프로그램)을 써본 적이 있나요?

- **아니오** → [Codex 앱 설치](/start/install-app/)로 간다.
- **네, 익숙하다** → 다음 질문으로.

### 3. VS Code 같은 코드 편집기를 이미 쓰고 있나요?

- **네** → 편집기 안에서 바로 쓸 수 있는 [IDE 확장](/surfaces/ide/)이 편할 수 있다. 다만 이 사이트의 실습은 앱 기준으로 작성되어 있으니, 처음이라면 [Codex 앱 설치](/start/install-app/)를 먼저 따라 하는 것을 권장한다.
- **아니오** → [Codex 앱 설치](/start/install-app/)로 간다.

## 확신이 안 서면

무엇을 골라야 할지 모르겠으면 그냥 [Codex 앱 설치](/start/install-app/)로 가면 된다. 이 사이트의 모든 실습은 앱을 기준으로 작성되어 있고, 나머지 창구는 앱에 익숙해진 다음 [다른 창구로도 쓰기](/surfaces/ide/) 섹션에서 다뤄도 충분하다.
