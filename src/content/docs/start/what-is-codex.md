## 목표

Codex가 무엇을 하는 도구인지 알고, 이 사이트가 다루는 범위를 파악한다.

## Codex는 무엇을 하는 도구인가

Codex는 OpenAI가 만든 코딩 [에이전트](/reference/glossary/#에이전트)다. 사람이 자연어로 "이런 걸 만들어줘" 또는 "이 에러를 고쳐줘"라고 요청하면, Codex가 코드를 작성하고 필요한 명령어를 실행해 결과를 보여준다.

일반적인 챗봇과 다른 점은, Codex는 대화만으로 끝나지 않는다는 것이다. 실제로 파일을 만들고, 고치고, 실행까지 한다.

## 이 사이트가 다루는 범위

이 사이트는 코딩을 배운 적 없는 학부생이 Codex로 웹앱 하나를 완성해보는 것을 목표로 한다.

**다룬다**

- Codex 앱 설치와 첫 대화
- 정적 웹앱 하나를 처음부터 끝까지 만들기
- GitHub Pages로 배포하기
- 만들면서 자주 겪는 문제 해결

**다루지 않는다**

- 프로그래밍 언어 문법 자체
- 데이터베이스, 서버 등 복잡한 백엔드 구성
