## 목표

IDE 확장이 앱과 무엇이 다른지 알고, 필요할 때 설치해서 써볼 수 있다.

## 사전 조건

- [ ] [완성 점검](/build/07-checklist/)까지 완료해 Codex 앱 사용에 익숙하다
- [ ] VS Code 같은 코드 편집기를 이미 쓰고 있다

## 앱과 무엇이 다른가

Codex 앱은 대화창 하나가 전부였다면, IDE 확장은 코드 편집기 화면 옆에 Codex 대화창이 붙어 있는 형태다. 코드를 직접 보면서 대화할 수 있어서, 이미 편집기에 익숙한 사람에게는 파일을 왔다갔다 확인하는 수고가 줄어든다.

반대로, 편집기 자체가 익숙하지 않다면 오히려 방해가 될 수 있다. 그래서 이 사이트는 앱을 기본 경로로 두고 있다.
