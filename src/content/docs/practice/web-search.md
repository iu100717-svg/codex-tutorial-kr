## 목표

Codex가 알고 있는 정보와 지금 인터넷에 있는 정보가 다를 수 있다는 것을 알고, 웹 검색이 필요한 상황을 구분할 수 있다.

## 사전 조건

- [ ] [틀린 코드를 자신 있게 내놓을 때](/pitfalls/hallucination/)를 읽었다

## 웹 검색이 필요한 상황

- 자주 바뀌는 정보를 다룰 때 (예: 특정 서비스의 최신 요금제, 최신 버전 정보)
- Codex가 모르는 최근 사건이나 자료를 참고해야 할 때
- Codex의 답이 오래된 정보 같다고 의심될 때

이 사이트의 [요금과 사용 한도](/start/pricing/)처럼, 자주 바뀌는 정보는 Codex가 답한 내용도 확인 없이 믿지 않는 것이 안전하다.

## 검색한 결과도 그대로 믿지 않는다

웹 검색을 거쳤다고 해서 항상 정확한 것은 아니다. 특히 출처가 불분명한 결과라면, Codex에게 "이 정보의 출처가 뭐야?"라고 물어 근거를 확인한다.
