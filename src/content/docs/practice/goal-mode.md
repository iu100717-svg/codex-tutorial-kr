## 목표

한두 문장으로 끝나지 않는, 여러 단계가 필요한 작업을 Codex에게 맡기는 방법을 안다.

## 사전 조건

- [ ] [고치고 다시 시키기](/build/04-iterate/)에서 한두 가지씩 요청하는 방식에 익숙하다

## 짧은 요청과 무엇이 다른가

지금까지는 "배경색을 바꿔줘"처럼 한 번에 하나씩 요청했다. 하지만 "포트폴리오 페이지에 다크 모드 전환 버튼을 추가하고, 사용자 설정을 기억하게 해줘"처럼 여러 단계가 필요한 작업도 있다. 이런 작업은 계획을 세우고, 여러 파일을 오가며, 중간중간 확인이 필요하다.

## 맡기기 전에 할 일

- 완성됐을 때의 모습을 먼저 설명한다 (무엇이 되면 끝인지)
- 중간에 판단이 필요한 부분이 있다면 미리 기준을 알려준다
- 작업이 길어질 수 있으니, [컨텍스트와 대화 관리](/concepts/context/)를 먼저 읽어둔다

## 요청 예시

```
포트폴리오 페이지에 다크 모드 전환 버튼을 추가해줘.

완성 기준:
- 버튼을 누르면 배경과 글자색이 어두운 색 조합으로 바뀐다
- 페이지를 새로고침해도 마지막으로 선택한 모드가 유지된다

작업이 여러 단계로 나뉜다면, 진행하면서 어떤 순서로 하고 있는지 알려줘.
```

## 진행 중 확인하는 법

작업이 길어지면 중간중간 "지금까지 뭘 했어?"라고 물어봐서 방향이 맞는지 확인한다. 다 끝날 때까지 기다렸다가 한꺼번에 확인하면, 잘못된 방향으로 간 부분을 되돌리는 비용이 커진다.
